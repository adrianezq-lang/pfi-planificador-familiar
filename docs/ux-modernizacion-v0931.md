# Modernización UX v0.9.31

Objetivos de esta iteración:

- mostrar primero las acciones frecuentes y plegar las secundarias;
- ocultar la valoración del menú hasta que el usuario decida abrirla;
- permitir marcar y desmarcar productos de compra de forma masiva;
- conservar cálculos, inventario, sobrantes, excepciones y compra mensual sin cambios de motor;
- mejorar jerarquía visual, tactilidad, legibilidad y adaptación móvil;
- mantener la compra mensual únicamente en Semana 1;
- conservar el recorrido por secciones de Mercadona.
